它是怎么运作的

先认识两个词 —— 节点：一台帮你转发上网流量的服务器，翻墙软件连上它，你的流量就借它出去； 订阅：一个网址，客户端（v2rayN / Clash）会按这个网址定期来取最新的节点列表，取一次更新一次。

① ChromeGo 的源 —— ChromeGo 的作者把免费节点放在云端几个固定地址里（结果里显示为「源1、源2」，就是原来 ip_1.bat、ip_2.bat 的编号）。 可以把它们想成几个快递柜：柜子地址永远不变，但里面的包裹会换—— 节点用几天就被封了，作者就换一批新的塞进去，有时连「包裹种类」（协议）都整个换掉。 所以每次点「一次拉全部」，你拿到的是这一刻柜子里的最新内容，跟昨天不一样很正常，别把某次拉到的链接当长期饭票，隔几天回来重拉一次更稳。 好消息是这些柜子地址在国内不用翻墙就能打开，所以这类拉取开不开代理都好用。

② 外部公共源（下面的「公共免费源」） —— 除了 ChromeGo，还有其他作者把四处收集的免费节点打包成订阅文件，放在 GitHub 上。 面板帮你把这些文件下载下来，只挑和 ChromeGo 四类对应的协议（vless/vmess/trojan/ss/hysteria/hysteria2），其他一律不要。 两类节点的待遇不一样：TCP 系（vless/vmess/trojan/ss）会挨个真握手试连一遍—— 就像打电话看对方接不接——接不通的直接扔掉，留下来的按速度排队； hy1 / hy2 走的是 UDP，这套「打电话」对它们没用（打通了也不代表能用），所以不试直接收， 死活交给客户端的「自动选择」组自己挑。 麻烦在于 GitHub 在国内直连打不开，所以有两条路： 你在上面「代理地址」框里填了代理，就走你的代理去拿；没填，面板就借一个国内的「搬运站」（镜像）替你拿，慢一点但也能拿到。 这些源不会自己更新——你点一次「立即更新」，面板才去拿一次（四个源同时开工，TCP 节点要挨个试连，通常一分多钟）。

③ 开代理软件 ≠ 开系统代理 —— 这俩是两件独立的事，很多人容易混。 打开代理软件（v2rayN / Clash）：相当于在你电脑里开了一个「中转站」窗口（比如 127.0.0.1:10808），谁把上网请求递给它，它就帮你转出去。 打开系统代理：只是在 Windows 里贴了张告示——「上外网请走那个中转站」——它自己不开门不干活，只给"会来看告示的程序"（主要是浏览器）指路。 所以会出现这种状态：软件开着、系统代理关着 → 浏览器没看告示、在直连（网页上不去外网），但面板这种自己知道地址的程序，照样能把请求递进中转站。 面板从不看系统代理那张告示，只认你填的「代理地址」——能不能借道出去，就看两件事：中转站开着没、节点是不是真的通。
